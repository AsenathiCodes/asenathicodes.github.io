# Asenathi — Python Portfolio

## Open the website on your phone
1. Extract this ZIP into a folder.
2. Open `index.html` in Chrome.
3. The `index.html` file now contains the styling and interactive JavaScript too, so it can work when Android opens it through a content/file viewer.

## Publishing
This folder is not public until uploaded to a hosting service such as GitHub Pages. Before launch, review the page and add a contact method you are comfortable making public. Never share passwords or verification codes.

## Files
- `index.html` — self-contained portfolio website.
- `style.css` — separate stylesheet retained for future editing.
- `script.js` — separate JavaScript retained for future editing.
